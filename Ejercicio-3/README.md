# Guía del repositorio

Este repositorio contiene tres ejercicios. Cada uno está organizado en su propia carpeta para que el Tech Lead (TL) pueda encontrarlos y revisarlos fácilmente.

## Estructura de carpetas

```text
IA-main/
├── README.md
├── Ejercicio-1/
│   └── ordenamiento_M_m.py
├── Ejercicio-2/
│   └── riwi-tres-cupos-borrador.txt
└── Ejercicio-3/
    ├── codigo-fuente/
    ├── nexora-link.md
    ├── prompt-original.md
    └── prompt-mejorado.md
```

## ¿Qué contiene cada carpeta?

- **Ejercicio-1:** contiene el archivo Python `ordenamiento_M_m.py`, correspondiente al algoritmo que ordena tres números.
- **Ejercicio-2:** contiene `riwi-tres-cupos-borrador.txt`, archivo generado durante la actividad práctica.
- **Ejercicio-3:** contiene el proyecto de la página NEXORA. En `codigo-fuente/` están los archivos del proyecto; `nexora-link.md` contiene el enlace de la página y los archivos `prompt-original.md` y `prompt-mejorado.md` guardan los prompts utilizados.

## Criterios de evaluación

| Criterio | Qué se revisa |
| --- | --- |
| Ejercicio 1 | El algoritmo ordena correctamente tres números, incluso si hay iguales. |
| Ejercicio 2 | Está el archivo generado en la actividad práctica. |
| Ejercicio 3 | La página funciona y se incluye el prompt usado. |
| Organización | Una carpeta por ejercicio y un README que los enumera. |
| Accesibilidad del repositorio | El TL puede abrir el repositorio. |

## Prompt utilizado para crear este README

> Lee esta carpeta .zip, analiza y créame un archivo README.md que guíe a mi TL, además, agrega este prompt como parte del mismo.

**Alcance solicitado:** el README debe servir únicamente como guía de las carpetas y archivos del repositorio, e incluir los criterios de evaluación anteriores.
